## Chosen strategy

Current browsers negotiate `controlled-turns-v1` in addition to `continuity-v2`. Semantic VAD remains low-eagerness, but both `create_response` and `interrupt_response` are false. One disposable provider microphone clone is gated while requesting/generating/playing AI output; raw camera/microphone recording stays unchanged. On drain, candidate speech is transcribed into an unsubmitted preview. Thinking pauses may create several segments without triggering another question. Send answer explicitly accepts those eligible segments and creates exactly one response. Try again discards them. I’d like to speak explicitly cancels/clears output; input reopens after acknowledgement. The model never receives a new response request on a noise/VAD event alone.

Rejected/unsubmitted text retained during disposal is annotated unverified before raw transcript publication. Only deliberately submitted, non-overlapping candidates enter the existing evidence pipeline; timestamps/item IDs stay intact. Speech-like hallucinations cannot be distinguished perfectly by text/VAD, so a human must review the recognized words before Send. This is an intentional half-duplex product trade-off, not hands-free conversational certification. No scoring/profile/report/hiring authority changed.

Continue now records pointer/handler/guard/native-failure and dependency started/completed/failed stages with one correlation ID. Pending state precedes native activation; capture, native audio resume and fresh HTML playback activation still execute in the same gesture. Disposal fences ownership before touching old resources and cannot latch the replacement operation. Recording native teardown is issued synchronously once before waiting for recorder finalization; late uploads/onstop cannot issue another close. Interruption also abandons outstanding completion-check intent. Cold refresh reconstructs the same durable attempt. Previous uploads and transcript retries remain independent, and recording gaps remain explicit.
