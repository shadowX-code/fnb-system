# FeedX Native Assistant business acceptance matrix

Generated from the canonical module projection, module-owned operations and reviewed coverage annotations. 129 modules include Space Station, a virtual navigation workspace with no independent business authority. There are 110 READ contracts and 2 separately authorized ACTION contracts.

Every registered READ has a business question and executable contract tests. PASS on those tests covers discovery, schema, policy, invalid arguments and human denial under fixtures. An authenticated answer requires an independent source comparison with `npm run qa:staging:assistant-certify`. A disabled capability, missing account or unexecuted scenario is BLOCKED. Undeclared query dimensions are UNSUPPORTED. Each module's settings are independent of this coverage inventory.

Coverage: 105 partial, 11 shared, 9 blocked, 4 not_applicable. Staging policy snapshot (22 November 2026 MYT): 85 enabled READs and 25 disabled READs.
