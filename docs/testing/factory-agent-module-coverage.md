# Factory External Agent capability coverage

Coverage describes implemented read capability, not permission or data quality. Available supports the module's canonical safe read contract. Limited identifies a supported read feature not yet exposed by the Gateway. Unavailable means there is no supported read capability. Redaction, source grants, bounded queries, historical nulls and empty Staging datasets do not lower coverage. Agent access is the separately enforced saved module grant; preserved review scope does not imply a full module grant.

Reassessment: **30 Available / 3 Limited / 0 Unavailable**, across the 33 Gateway entries (32 sidebar modules plus Production Records), with 34 human routes retained, 65 resources and 97 mappings. No grants, mappings, credentials or business records change.
